# Nexus — Telegram × Discord в одном приложении

Единый веб-мессенджер: личные чаты в духе Telegram + серверы и каналы в духе Discord.

## APK (Android-приложение)

В корне лежит **`Nexus.apk`** — нативная Android-обёртка (Android 8+, WebView):
кнопка-шестерёнка меняет адрес сервера на лету, выбор файлов для вложений,
скачивание файлов из чата, экран ошибки с действиями, иконка в списке приложений.
Весь функционал (серверы, каналы, реакции, поиск, WebSocket) работает как в браузере.

Сейчас в APK зашит публичный адрес туннеля к этому серверу Nexus — работает,
пока туннель и сервер запущены. Чтобы приложение жило постоянно, поднимите
сервер на бесплатном хостинге и укажите его адрес в приложении (шестерёнка),
см. **DEPLOY.md** (Render / Fly.io / VPS / Docker — 5–10 минут, без карты для Render).

Исходники обёртки: `/home/user/nexus-android` (Gradle-проект, `gradle assembleDebug`).

## Запуск

```bash
cd nexus
npm install
npm start          # http://localhost:3000  (PORT=8080 npm start, чтобы сменить порт)
```

Демо-аккаунт: **demo / demo1234** (кнопка «Демо-вход в один клик» на экране входа).
Можно зарегистрировать и свой аккаунт.

## Что внутри

**Telegram-часть**
- Личные чаты один на один с любым пользователем
- Список диалогов с превью последнего сообщения, временем и счётчиком непрочитанных
- Онлайн-статусы в реальном времени

**Discord-часть**
- Серверы (сообщества), создание своих с названием
- Текстовые каналы: создание, удаление (владельцем), темы каналов
- Панель участников сервера с ролью «Владелец», онлайн/оффлайн группировка

**Общее**
- Реал-тайм сообщения (WebSocket), индикатор «печатает…»
- Редактирование и удаление своих сообщений (владелец сервера может удалять чужие в своих каналах)
- Реакции-эмодзи (👍 ❤️ 😂 …), ответы с цитатой, редактирование inline
- Прикрепление файлов и изображений (до 10 МБ) с превью и скачиванием
- Поиск по сообщениям (глобальный, `/` — фокус на строке, Enter — поиск)
- Непрочитанные счётчики на каналах, диалогах, серверах и иконке вкладки
- Звуковое уведомление о новых сообщениях
- Аватары генерируются автоматически из имени (градиент + инициалы)

## Технологии

- **Backend:** Node.js, Express, WebSocket (пакет `ws`), хранение — JSON-файл (`data/db.json`) с атомарной записью
- **Frontend:** чистый HTML/CSS/JS, без сборки
- Пароли — scrypt-хеши, сессии — токены в `data/db.json`

## Данные

Всё хранится локально в `data/db.json` (демо-данные создаются при первом запуске)
и `public/uploads/` (загруженные файлы). Для чистого демо удалите папку `data/`.

> Для продакшена замените JSON-хранилище на PostgreSQL и добавьте HTTPS/rate-limit —
> это осознанно опущено для демо.
