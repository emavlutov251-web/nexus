# Как раздать Nexus на телефоны (APK) и держать сервер онлайн навсегда

APK (`Nexus.apk`) — это **клиент**. Чат идёт через ваш сервер Nexus.
Сейчас в APK зашит адрес бесплатного туннеля, который живёт, пока запущен
этот компьютер/песочница. Чтобы два телефона (или сто) общались всегда —
поднимите сервер постоянно за 5 минут.

## Шаг 1. Выложите сервер на бесплатный хост

### Вариант A — Render.com (бесплатно, без карты)
1. Зайдите на https://render.com → Sign up (через GitHub проще).
2. New → Web Service → подключите этот репозиторий/папку `nexus/`
   (или загрузите `nexus/` в свой GitHub-репозиторий и выберите его).
3. Настройки: Build Command = `npm install`, Start Command = `npm start`, Plan = Free.
4. Нажмите Create Web Service — через пару минут получите адрес вида
   `https://nexus-xxxx.onrender.com`
5. Откройте `https://nexus-xxxx.onrender.com` в браузере — увидите экран входа Nexus.

> Замечание про бесплатный план: сервис засыпает после 15 минут простоя
> (первый запрос будит ~30–60 с), а файлы `data/db.json` могут сбрасываться
> при пересборке. Для постоянного хранения истории — платный диск Render
> или Fly.io с томом (вариант B), либо просто периодический бэкап папки `data/`.

### Вариант B — Fly.io (бесплатный лимит, с томом для данных)
```bash
fly launch --name my-nexus --dockerfile Dockerfile   # Dockerfile уже в проекте
fly volumes create nexus_data --size 1
# в fly.toml добавьте: [mounts] source = "nexus_data"  destination = "/app/data"
fly deploy
fly open   # адрес вида https://my-nexus.fly.dev
```

### Вариант C — любой VPS (дешёвый или свой)
```bash
sudo apt install nodejs npm git
git clone <ваш-репозиторий> && cd nexus && npm install
PORT=3000 node server.js   # дальше — nginx + certbot по желанию
```

### Вариант D — Docker (где угодно)
```bash
docker build -t nexus-app .
docker run -d -p 3000:3000 -v nexus-data:/app/data nexus-app
```

## Шаг 2. Укажите адрес сервера в приложении
1. Установите `Nexus.apk` (нужен Android 8+; при установке разрешите «установку из неизвестных источников»).
2. Откройте Nexus → **шестерёнка** в правом верхнем углу → вставьте адрес из шага 1
   (например `https://nexus-xxxx.onrender.com`) → «Сохранить».
3. Войдите демо-аккаунтом `demo / demo1234` или зарегистрируйтесь — и чатите.

Чтобы собрать APK заново с другим адресом по умолчанию:
```bash
# в nexus-android/app/src/main/java/app/nexus/messenger/MainActivity.java
# поменяйте DEFAULT_SERVER на свой адрес, затем:
gradle assembleDebug   # результат: app/build/outputs/apk/debug/app-debug.apk
```

## Установка на телефон
1. Скачайте `Nexus.apk` на телефон (откройте ссылку на файл с того же компьютера,
   перешлите себе в мессенджер, через облако и т.п.).
2. Тапните по файлу → «Установить». Антроник покажет предупреждение о неизвестном
   источнике — разрешите на время установки.
3. Иконка «Nexus» появится в общем списке приложений.

## Что работает в приложении
Весь функционал веб-версии без ограничений: личные чаты, серверы и каналы,
реакции, ответы, редактирование/удаление, вложения (до 10 МБ), поиск
(`/` + Enter — поиск по сообщениям), непрочитанные счётчики, онлайн-статусы,
уведомление «печатает…», мультивкладка. WebSocket реал-тайм идёт через тот же
адрес, ничего дополнительно настраивать не нужно.

## Частые вопросы
- **Два телефона не видят друг друга?** Они должны быть на одном сервере:
  проверьте шестерёнку — адрес должен совпадать.
- **"Не удалось подключиться"** — сервер заснул (бесплатный план) или адрес неверен;
  откройте адрес в браузере телефона — если не открывается, сервер не запущен/не тот URL.
- **Данные пропали после пересборки** — см. «Замечание про бесплатный план» в варианте A.
- **Нужен иконка в Google Play?** Тогда соберите release-подпись и опубликуйте;
  текущий APK — debug-сборка для прямой установки (sideload).
